# Supplementary information

Upstream **Mask R-CNN** implementation: [Matterport Mask_RCNN](https://github.com/matterport/Mask_RCNN) (MIT License; see `LICENSE-Matterport-MIT.txt`).

This repository vendors `mrcnn/` and `samples/coco/` from that project and adds custom model modules (`model_203.py`, `model_wide_ResNet.py`, `model_143.py`, `last_model.py`) derived from the project’s `model.py` and local wide-ResNet variants.
